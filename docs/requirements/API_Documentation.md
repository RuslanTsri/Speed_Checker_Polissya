# API Documentation (Postman/Swagger) — Tempo Metrics

Ця документація описує взаємодію мобільного додатка з бекендом Supabase.

## Ендпоінт 1: Отримання списку гравців команди
**Опис:** Отримує масив гравців, закріплених за конкретною командою (таблиця `players`).

* **Метод:** `GET`
* **Шлях:** `/rest/v1/players`
* **Параметри запиту:**
  * `team_id`: `eq.{uuid}` (ідентифікатор команди для фільтрації)
  * `select`: `*` (отримати всі поля)
* **Заголовки:**
  * `apikey`: `[YOUR_SUPABASE_ANON_KEY]`
  * `Authorization`: `Bearer [USER_TOKEN]`

**Приклад успішної відповіді (200 OK):**
```json
[
  {
    "id": "a1b2c3d4-e5f6-7890-1234-56789abcdef0",
    "name": "Руслан Цимбалюк",
    "team_id": "99bbcc11-2233-4455-6677-889900aabbcc"
  },
  {
    "id": "f0e9d8c7-b6a5-4321-0987-654321fedcba",
    "name": "Іван Богун",
    "team_id": "99bbcc11-2233-4455-6677-889900aabbcc"
  }
]
```

## Ендпоінт 2: Збереження результату забігу
**Опис:** Реєструє новий замір часу для конкретного гравця в межах створеної тренувальної сесії (таблиця results). Дозволяє зберігати як загальний час, так і час проходження проміжних гейтів.

* **Метод:** \`POST\`
* **Шлях:** \`/rest/v1/results\`
* **Тіло запиту (JSON):**
* **Заголовки:**
  * `Content-Type`: `application/json`
  * `Prefer`: `return=representation (щоб сервер повернув створений об'єкт)`
  ```json
  {
  "session_id": "sess-55aa-44bb-33cc-22dd11ee00ff",
  "player_id": "a1b2c3d4-e5f6-7890-1234-56789abcdef0",
  "full_time": 4.523,
  "gates": [1.210, 2.845, 4.523],
  "is_best": true
  }
  ```

**Приклад успішної відповіді (201 Created):**
  ```json
  {
  "id": "d4c3b2a1-1234-5678-90ab-cdef01234567",
  "created_at": "2026-03-26T14:30:00.000Z",
  "session_id": "sess-55aa-44bb-33cc-22dd11ee00ff",
  "player_id": "a1b2c3d4-e5f6-7890-1234-56789abcdef0",
  "full_time": 4.523,
  "gates": [1.210, 2.845, 4.523],
  "is_best": true
  }
```
