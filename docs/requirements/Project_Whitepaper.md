# Project Whitepaper: Tempo Metrics
*(Академічна пояснювальна записка / STUDENT_DOCS)*

## ВСТУП

**Актуальність теми.** У сучасному професійному спорті точність вимірювання фізичних показників є критично важливою для побудови ефективного тренувального процесу. Використання ручних секундомірів призводить до значних похибок через людський фактор. Розробка автоматизованої системи **Tempo Metrics** дозволяє отримувати об'єктивні дані у реальному часі, що є актуальним для цифровізації підготовки гравців Футбольних клубів (далі ФК).

**Об'єкт дослідження** — процес фізичної підготовки та тестування швидкісних характеристик спортсменів у професійних ФК.

**Предмет дослідження** — програмно-апаратні методи та засоби автоматизації вимірювання, збору та аналізу результатів спортивних тестувань.

**Мета роботи** — розробка крос-платформного мобільного застосунку для автоматизації процесу спортивного тестування з використанням Bluetooth-датчиків та хмарних технологій збереження даних.

**Завдання роботи:**
1. Проаналізувати існуючі методи вимірювання швидкісних показників.
2. Спроектувати архітектуру мобільного застосунку для взаємодії з BLE-сенсорами.
3. Реалізувати систему ідентифікації та управління профілями гравців.
4. Розробити функціонал для експорту та візуалізації аналітичних даних.

**Практичне значення отриманих результатів** полягає у створенні працюючого прототипу системи, що впроваджується у тренувальний процес різних ФК, забезпечуючи точність замірів до тисячних значень, та автоматичну синхронізацію з центральною базою даних (далі БД).

## ПЕРЕЛІК УМОВНИХ ПОЗНАЧЕНЬ

* **BLE (Bluetooth Low Energy)** — енергоефективна технологія бездротового зв'язку.
* **OTA (Over-The-Air)** — технологія оновлення програмного забезпечення «по повітрю».
* **BaaS (Backend as a Service)** — модель надання хмарних послуг для серверної частини додатків.
* **CRUD (Create, Read, Update, Delete)** — основні операції роботи з даними.
* **UI/UX** — інтерфейс та досвід взаємодії користувача з програмою.

## РОЗДІЛ 1. ОПИС ТЕХНОЛОГІЧНОГО СТЕКУ

Для реалізації проєкту **Tempo Metrics** було обрано сучасний стек технологій, що забезпечує швидкість розробки та високу продуктивність.

### 1.1. React Native & Expo
Вибір цього фреймворку обумовлений необхідністю крос-платформної розробки для iOS та Android з єдиною кодовою базою. Expo надає потужні інструменти для роботи з нативними модулями, зокрема \`expo-updates\` для OTA-оновлень, що критично для швидкого виправлення багів у польових умовах без повторної модерації в магазинах додатків.

### 1.2. TypeScript
Використання типізованої мови програмування дозволяє мінімізувати кількість помилок на етапі розробки. Це особливо важливо при обробці складних структур даних, що надходять від Bluetooth-сенсорів, та при забезпеченні надійної взаємодії з API бекенду.

### 1.3. Supabase (PostgreSQL)
Як бекенд-платформа обрано Supabase. Це забезпечує надійне збереження даних гравців та результатів тестів у реляційній базі даних PostgreSQL. Використання вбудованої системи Auth спрощує реалізацію безпечної авторизації для тренерського штабу ФК.

### 1.4. NativeWind (Tailwind CSS)
Для стилізації інтерфейсу обрано підхід Utility-first, що дозволяє створювати адаптивний та контрастний дизайн. Це важливо для використання додатка на відкритих стадіонах при яскравому сонячному освітленні, де читабельність інтерфейсу є пріоритетною.

### 1.5. Bluetooth Low Energy API
Центральною частиною системи є інтеграція з бібліотеками для роботи з Bluetooth-протоколом. Це забезпечує низьку затримку (low latency) при отриманні сигналів від оптичних гейтів, що дозволяє фіксувати результати з точністю до мілісекунд.

## ВИСНОВКИ

У ході виконання роботи було спроектовано та реалізовано мобільний застосунок **Tempo Metrics**, який вирішує проблему автоматизації збору швидкісних показників спортсменів. Впровадження сучасних технологій дозволило створити масштабовану систему, що працює в режимі реального часу. Результати тестувань підтверджують високу точність даних та зручність інтерфейсу для тренерського складу. Проєкт має потенціал для подальшого розширення функціоналу, зокрема впровадження AI-аналітики для прогнозування фізичного стану гравців.
